# 考试成绩 Excel 导入

模板列为：考试批次编码、报名编号、姓名、科目编码、准考证号、考试日期、出席状态、分数、结果、结果发布日期、备注。

导入分两阶段：

1. `POST /api/imports/exam-results/preview` 上传 xlsx。系统限制大小和行数，以批次编码、报名编号和科目编码匹配，检查重复、定点分数、结果冲突与官方确认锁定。此阶段不改成绩。
2. `POST /api/imports/exam-results/{batch_id}/confirm` 携带幂等键。只有 `READY` 行写入，姓名警告行等待人工核对，冲突和无效行跳过。写入后的成绩为 `SUBMITTED`，仍需具备权限的人员官方确认。

预检批次只允许创建人访问，两小时过期。原始工作簿不长期保存；预检载荷加密，审计仅记录批次数量与状态统计，不记录准考证号或完整原始行。公式内容不会进入导出的错误工作簿，因为当前错误报告使用结构化 JSON 展示；后续若增加 Excel 错误报告，所有以 `= + - @` 开头的文本必须转义。
