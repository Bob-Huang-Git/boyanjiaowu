# 学员 Excel 导入

从“学员 Excel 导入”页面下载模板。模板列固定为姓名、证件类型、证件号码、手机号、性别、出生日期、文化程度、来源渠道、课程编码、课程版本、报名日期、班级编码、备注。

上传 `xlsx` 后先预检，默认最大 10 MB、2,000 行。预检只保存加密的短期确认数据与脱敏结果，不创建学员。每行可能是可创建、明确证件重复、疑似重复、无效或跳过。

确认阶段仅处理学员主档：明确证件重复不会创建；疑似重复必须选择关联已有学员、填写理由强制新建或跳过。课程、报名和班级列会在预检结果中提示“当前批次不执行”，不会被静默忽略。相同确认幂等键重复提交不会重复创建学员。

导入结果不保存完整证件号。导出错误报告时，任何以 `=`, `+`, `-`, `@` 开头的文本都必须转义，防止 Excel 公式注入。当前界面提供预检；完整错误报告下载将在导入体验完善时补充。
