# 数据约定

- 公有对象 ID 使用 UUID 字符串；数据库关键外键和唯一约束必须真实存在。
- 金额数据库字段使用整数分，后缀 `_amount_cent` 或 `_price_cent`；禁止 float 金额计算。
- 课次、出勤和可结算时长使用整数分钟；课时换算保存规则版本。
- 数据库时间戳为 UTC。SQLite 不存时区元数据，因此写入前统一转 UTC；上课日期、政策日期、住宿夜日期使用独立 `date`。
- 已确认考勤、官方成绩、资金、补贴和正式报表以撤销、冲正、调整或新 revision 更正。
- 服务层负责事务边界；Repository 只封装重复查询。不建立第二套实体模型。
- 业务角色、课程、科目、政策和模板版本存配置或业务表，不写死在枚举中。
