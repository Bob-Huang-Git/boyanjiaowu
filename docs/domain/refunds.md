# 退费

当前受控算法为 `PRO_RATA_BY_ATTENDED_MINUTES`。合同总分钟取报名绑定的 `CurriculumVersion.total_minutes`；已上分钟只累计该报名跨全部班级成员经历关联的 `LOCKED` 考勤。超过合同总分钟时封顶并产生警告。

已消费金额以 `培训费应付分 × 锁定出勤分钟 / 合同总分钟` 计算，支持 `HALF_UP`、`FLOOR` 和 `CEILING`。计算仅使用整数除法与余数。可退金额不超过实际分配到培训费的收款，并扣除已消费、管理费和历史有效退款。

每次计算新增不可覆盖的快照，并逐条保存考勤 ID、修订号、分钟和锁定时间。提交时再次校验考勤；发生修订则标记过期并要求重算。批准和实际退款是两个动作，实际付款通过 `RefundAllocation` 追溯到原 `PaymentAllocation`。申请人默认不能自审。
