- **建立日期**：2026-09-23
- **来源**：《职业培训教务系统 Codex 提示词 V3.0》各 Prompt「测试至少覆盖」与「最终输出」小节，**逐条原样录入**

## 勾选图例

| 标记 | 含义 |
| --- | --- |
| `[x]` | **已覆盖**——有明确断言，且已实测通过 |
| `[~]` | **部分覆盖 / 需人工复核**——流程走通但缺关键断言，或仅覆盖正向路径 |
| `[ ]` | **未覆盖** |

> ⚠️ `[~]` 与 `[ ]` **不等于功能未实现**。判定功能是否实现请看 `docs/architecture/design-conformance-review-2026-09-23.md`；本清单只回答「有没有被测试守住」。

## 维护约定

1. 补测试时**同时**把对应条目改为 `[x]`，并在条目后追加 `（<测试文件名>::<用例名>）`。
2. **任何 Sprint 在打 tag 前，必须核对本清单**：新增功能对应条目不得为 `[ ]`。
3. 新增需求产生的用例追加到对应 Prompt 小节末尾，不得插入打乱既有编号。

**结论**：P1–P5 的 48 条必测用例中，**13 条完全未覆盖、12 条只覆盖了正向路径**。其中 4 类并发用例（并发建档、并发滚班、并发退款、并发申报）仍全部为零，直接影响学籍与资金正确性。P6–P11 的 82 条尚在未开始阶段。
