## 部署基线

开发环境使用 Windows 原生 Python 虚拟环境和 Node.js。生产环境使用阿里云 ECS Linux 的 Nginx、systemd、Uvicorn、SQLite、OSS 与 cron 或 systemd timer。后续阶段不得增加 Docker、Redis、Celery、RabbitMQ、Kafka、Kubernetes、第二套数据库或第二套迁移工具。SQLite 继续作为第一期唯一数据库，位于 ECS 本地数据目录，应用固定为单实例和单 Uvicorn worker。

## Sprint 5 实际边界

财务模块是业务资金台账，不是会计总账。当前记录线下确认的收付款，不接支付网关、税务发票或银行自动对账；教师付款不计算个税、工资和社保。下一阶段进入退役士兵资格、餐补、住宿补贴与学校垫资，政府补贴不得混入本阶段学员收款。

## Sprint 1 精确变更清单

新增 Student、StudentIdentifier、VeteranProfile、CourseCatalog、CourseOfferingVersion、CourseEnrollment、ClassMembership 及其索引/约束；实现身份信息加密与 HMAC 查重、学员创建/查重、课程版本管理、报名、滚班服务及 API；建立学员 360 的基础视图与班级来源参数；在 SQL 层落实组织/班级范围；覆盖多课程报名、同课程再次报名、滚班历史、重复身份、越权访问和并发写入测试。

## Sprint 1 实际边界

已完成学员、证件、课程与版本、报名、班级成员经历和学员 Excel 的两阶段预检/确认。预检中的课程、报名和班级列会明确提示为不执行；完整组合导入、班级滚动、课程版本编辑页、导入错误报告下载和前端班级筛选恢复留待后续迭代。Sprint 2 只进入课次、教师、考勤与录屏，不改变本阶段的报名和成员经历模型。
