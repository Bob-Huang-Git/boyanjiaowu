# S6.1 施工规格：退役身份与补贴前端入口

- **批次目标**：让已交付的 Sprint 6 后端能力从现有 Vue 前端可进入、可查看，并开放低风险的核心操作。
- **约束**：不新增 Docker；金额仍以整数分传输；权限由后端最终判定；前端不编造补贴政策。

## 页面与接口

| 页面区域 | 接口 | 本批能力 |
| --- | --- | --- |
| 学员 360 / 退役与资助 | `GET/POST /students/{id}/veteran-identity` | 查看、建立退役身份主档 |
| 学员 360 / 核验历史 | `GET/POST /veteran-identities/{id}/verifications` | 查看历史、追加核验结论 |
| 学员 360 / 属性历史 | `GET /veteran-identities/{id}/attributes` | 查看时间性身份属性 |
| 学员 360 / 报名资格 | `GET/POST /enrollments/{id}/funding-case` | 逐报名查看或建立资格案 |
| 学员 360 / 补贴摘要 | `GET /students/{id}/allowance-summary` | 区分应付、已付、未付 |
| 资助工作台 / 项目 | `GET/POST /funding-programs` | 查看、新建政府项目 |
| 资助工作台 / 出勤事实 | `GET /attendance-day-facts`、`POST .../confirm` | 筛选、查看和确认每日事实 |
| 资助工作台 / 住宿事实 | `GET /lodging-night-facts` | 按报名查看住宿夜事实 |
| 资助工作台 / 政策 | `GET /allowance-policies` | 查看政策版本和生效期 |
| 资助工作台 / 应付 | `GET /allowance-payables`、`POST .../payments` | 筛选应付、登记支付 |

## 权限与数据表达

- 页签、按钮按 Sprint 6 权限点显示；接口继续执行服务端权限和组织隔离。
- 退役证号只展示后端脱敏值；本批不提供明文查看入口。
- 补贴金额只在展示层由分换算为元；请求仍提交整数分。
- 核验历史和属性历史只追加、只读取，不覆盖旧记录。

## 本批不宣称完成的范围

- 政府项目版本维护和可选版本下拉尚未接入，因此建立资格案暂时输入已发布版本 ID。
- 班级 360 内的每日事实入口、住宿登记与审核、权益计算与调整、学校垫资成本页面仍待后续 S6 批次。
- 前端尚无自动化测试框架；本批以 `vue-tsc`、生产构建和全量后端回归作为自动验证，人工验收仍需业务账号和数据。
