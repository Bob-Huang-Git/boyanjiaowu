# 财务数据安全

收款录入、确认、分配和冲正使用独立权限；退款申请、计算、审批、付款和冲正分离；教师结算计算、提交、审批与付款分离。退款与教师结算默认禁止提交人自审。后端在 SQL 查询中限制组织范围，前端按钮不代替鉴权。

外部交易号加密保存，普通 API 只返回末四位，不返回密文、银行卡号、本地附件路径或支付凭据。付款凭证继续引用本地 `FileObject`，下载权限为 `finance.evidence.read`。

应收、收款分配、代缴、退款、结算和付款的关键动作写入 `AuditLog`。审计详情只记录整数分、状态和必要原因，不记录完整交易号或凭证内容。正式资金记录不能物理删除，错误通过追加调整或冲正处理。
