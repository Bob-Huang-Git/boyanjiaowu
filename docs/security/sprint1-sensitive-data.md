# Sprint 1 敏感信息

手机号和证件号不以明文保存。写入前，手机号先规范化；证件号按证件类型规范化，中国居民身份证保留字符但统一大写 `X`。系统使用 AES-GCM 保存密文，使用独立 HMAC-SHA-256 盲索引用于精确查重和查询。

生产环境必须提供 `PII_ENCRYPTION_KEY` 和 `PII_BLIND_INDEX_KEY`，且两者不同。密钥为 Base64 编码的 32 字节值；密文记录保留 `key_version`，为未来轮换预留。开发和测试环境使用受限的内置测试密钥，绝不能用于生产。

普通列表和详情只显示手机号掩码、证件类型及后四位。证件明文只能调用独立接口，要求 `student.sensitive.reveal` 权限和非空理由；每次成功查看都会留下审计记录。前端不接收加密或盲索引密钥，审计详情也不保存证件号或手机号。
